# 开发说明

## 模块

- app/exam_print.py：输入收集、照片分组、旋转拆页、OCR排序及打印排版；页脚缺失时按大题/小题号衔接推断，不成立再回退文件名顺序，并记录页序依据。
- app/pdf_exam_print.py：扫描PDF分套、pypdf裁切与拼版，保留嵌入图像数据。
- app/exam_names.py：内容命名、Windows文件名清理及同名结果避让。
- app/completed_inputs.py：核验最终PDF页序与尺寸、生成核验预览、归档原文件；非页脚OCR来源的批次走降级核验，只查页数/尺寸/方向并标注未经页脚复核。
- app/output_batches.py：批次暂存、最新/历史轮换、拼接预览、压缩打包和归档记录路径更新。
- app/project_paths.py：统一工程根目录；避免依赖当前工作目录。
- app/setup_local.py：创建.venv、优先离线安装和本地环境检查。
- app/install_poppler.py：缺失时从上游GitHub恢复Windows Poppler。
- app/read_page_numbers.ps1：Windows内置OCR，离线识别。

## 测试

`.venv\Scripts\python.exe -m unittest discover -s tests -v`

测试涵盖重名保护、输入改变、组内搬动失败回滚、核验失败保留输入、外部文件不搬动、最新结果轮换、空运行及全失败不替换最新结果。
依赖变更或PDF排版变更还应使用真实试卷做完整运行，渲染PDF并核对页脚与题目边缘。

## 命令行

```powershell
# 默认输入、自动核验归档、发布最新结果
.venv\Scripts\python.exe app\exam_print.py
# 仅验证运行，不归档输入，输出到指定目录
.venv\Scripts\python.exe app\exam_print.py --keep-inputs --out D:\Temp\exam-check
# 显式整张A3输出
.venv\Scripts\python.exe app\exam_print.py --paper A3 --mode straight
```

默认仍是A4双面拼接。PDF分套目前只自动处理四个连续页码；PDF旋转标记、明显透视和倾斜不在完整自动校正能力内。自动页脚核验失败时不归档原文件。

## 开源依赖

- Pillow：照片、画布和预览。
- pypdf：https://github.com/py-pdf/pypdf
- pypdfium2：https://github.com/pypdfium2-team/pypdfium2
- Poppler：https://poppler.freedesktop.org/ ，Windows打包 https://github.com/oschwartz10612/poppler-windows

本机Poppler已复制到tools/poppler；binaries.json和upstream-manifest.json记录本机初始工具版本与校验值。Git不提交DLL、安装包和虚拟环境；安装脚本可恢复依赖。
离线wheels适用于本机Windows x64 Python 3.14。不同Python版本可能需要联网重新获取对应安装包。

## macOS

Python 3.11+，macOS13+。启动入口为根目录.command脚本，环境位于.venv/bin/python。mac_ocr.py通过PyObjC调用系统Vision；desktop.py封装Finder打开和本地Poppler查找。Mac标准流程使用Vision和PDFium，无需Homebrew；Poppler仅是可选复核工具。Mac测试包含真实中文页码和教辅页码OCR。
